Quick Calc Pad: how it's built

One Astro page, a script that runs in the browser, math.js, and localStorage. Published free on GitHub Pages.

In plain language

Astro builds the page. A <script> on it runs in the visitor's browser and does all the work. “Static” only means there's no server behind it.

As you type, our own translator rewrites friendly phrases into plain math, and math.js calculates the answer, reusing earlier answers by name.

Each tab's text is saved in localStorage, a small notebook the browser keeps for one site. No server, no accounts, no API keys.

→
(21/100) * 150
=
31.5
vat = rate of net
→
vat: rate * net
=
31.5
(2 + 3) * 4
→
(unchanged)

20

Our translator handles every %, so how math.js treats % doesn't matter. That's still checked in the first build step.

Translatorsrc/lib/translate.ts
Rules in order: A% off B, B ± A%, A of B, any other A%. Keeps a leading name =.

Sheet Calculatorsrc/lib/calculate.ts
Text → one result per line, top to bottom. Names come from name = … or line<N>. One bad line never stops the others. Rounds to 2 decimals and shows bare percentages as 21%.

Closest known name, at most 2 letters off, otherwise only the explanation.

Where it can break

  • Unit words (m, in, cm): math.js may read them as units, so that line shows “Units aren't supported yet.”
  • Inserting a line in the middle shifts the automatic lineN names. That's accepted; renaming a line fixes its name.
  • Using a name before it's defined shows an error on that line.
  • Unreadable saved data means starting fresh from the templates.

Please check

  • Errors are marked on the line's result row (red, wavy, with the tooltip there), not inside the typed text. That's the cost of using a simple textarea.
  • The palette above is a proposal. The font is Kalam, your pick.
  • Repo quick-calc-pad, so the live address is <user>.github.io/quick-calc-pad.
